# Shared editing instructions

This GitHub repository is the shared source for ChatGPT/Codex and Claude.

- Fetch the latest origin/main before work. Use a separate task branch and a pull request. Do not force-push main or overwrite another assistant's work.
- Read README.md and DEPLOYMENT.md before editing. Record material decisions and deployment commits in the repository; conversation history is not shared between assistants.
- Preserve URLs, canonical tags, structured data, Amazon book associations, analytics IDs and original artwork unless the task changes them.
- Kevin Coulston is the only creator credited anywhere on this site. Do not credit or mention anyone else as a creator, voice or collaborator.
- Snap is the orange baby T-Rex (a boy). Daisy is the blue baby T-Rex with the red bow (a girl). Abigail is Alexis' best friend.
- Do not replace Kevin's artwork with AI artwork or clipart. The clouds are cut from Kevin's own scene art and must stay level; the header must not be white (the logo is white).
- Keep the sister sites' editorial copy distinct. This site lists only the 3 Alexis and the T-Rexes books; the drawing books are mentioned with links out to FirstArtBooks.com.
- Keep credentials, Cloudflare API tokens, .env files and account secrets out of Git.
- Keep source edits and deployed code synchronized: commit the exact deployed state (dist/ is tracked) and record its commit SHA.
- Verify desktop/mobile layouts and the count game for UI changes. Report what was checked and any remaining limitation.
